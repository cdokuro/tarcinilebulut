Gizlilik Politikası

Son güncelleme: 6 Kasım 2026

Uygulama ne yapar?

"Tarçın ile Bulut" uygulaması, yalnızca kanal sahibinin kendi bilgisayarında çalışan bir yükleme aracıdır. YouTube Data API ile kanal sahibinin kendi bölümlerini Tarçın ile Bulut kanalına yükler, başlık/açıklama/küçük resim ayarlar ve kanalın kendi yükleme listesini okur.

Hangi verileri kullanır?

Uygulama başka kullanıcıların hiçbir verisini toplamaz, saklamaz veya paylaşmaz. YouTube erişim izni (OAuth token) yalnızca kanal sahibinin bilgisayarında saklanır ve üçüncü taraflara gönderilmez. Uygulamanın web sitesi çerez veya izleme aracı kullanmaz.

İzleyiciler

Videolar YouTube'da "çocuklara özel" olarak yayınlanır; izleyicilerle ilgili veriler YouTube/Google tarafından kendi gizlilik politikalarına göre işlenir: policies.google.com/privacy. Uygulamamız bu verilere erişmez.

Google API Hizmetleri

Google API'lerinden alınan bilgilerin kullanımı Google API Services User Data Policy kurallarına (Limited Use dahil) uyar. İzni istediğiniz an myaccount.google.com/permissions adresinden geri alabilirsiniz.

İletişim

Sorularınız için YouTube kanalımız üzerinden bize ulaşabilirsiniz.

English summary

The "Tarçın ile Bulut" app is a private upload tool that runs only on the channel owner's computer. It uses the YouTube Data API to upload the owner's own episodes to the Tarçın ile Bulut channel, set titles, descriptions and thumbnails, and read the channel's own uploads list. It does not collect, store or share any data about other users. The OAuth token stays on the owner's computer. This website uses no cookies or tracking. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: via our YouTube channel.
